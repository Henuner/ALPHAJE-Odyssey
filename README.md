# ALPHAJE's Odyssey

A long-lived personal digital space for exploring, creating, reflecting, and growing.

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Local MDX content with front matter
- Framer Motion and CSS animation

## Scripts

```bash
npm run dev
npm run lint
npm run build
```

## Content

Create MDX files in:

- `content/knowledge`
- `content/projects`
- `content/reflection`
- `content/creative`

Each file uses front matter for metadata and is committed through Git.
