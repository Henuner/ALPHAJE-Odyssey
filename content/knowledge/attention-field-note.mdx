## Why attention matters

Attention is a way for a model to compare one token with the surrounding context and decide which
parts deserve more weight.

<Callout>
The goal of this note is not to memorize formulas, but to build an intuition that can survive
implementation details.
</Callout>

## A tiny formula

Scaled dot-product attention can be written as:

$$
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

## Implementation sketch

```ts
type AttentionInput = {
  query: number[][];
  key: number[][];
  value: number[][];
};

export function describeAttention(input: AttentionInput) {
  return `Compare ${input.query.length} queries with ${input.key.length} keys.`;
}
```
