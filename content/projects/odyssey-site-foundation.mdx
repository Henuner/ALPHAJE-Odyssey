## Project background

This site is designed as a personal digital space rather than a resume or a plain blog.

## Technical direction

The first version favors boring, maintainable infrastructure:

- App Router pages
- Git-managed MDX
- Shared content components
- A warm visual system that can grow into a richer world

## Implementation process

The content model starts with four regions: Knowledge, Projects, Reflection, and Creative.
Each region has list and detail pages, so future content only needs a new MDX file.

## Summary

Phase 1 should make the site usable, readable, and ready for years of additions.
